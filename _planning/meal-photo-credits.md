# Meal photo sources

Photos in `public/meals/` come from Wikimedia Commons (openly licensed, no API
key needed), chosen by searching each dish's own category and picking the
closest landscape shot. They're stock photos of the *dish*, not the actual
cottage meal, so some are nearer the mark than others — `whatevers-left` and
`leftovers` are stand-ins by nature, and no photo shows the crudités that go
with the grilled cheese. Swap any of these out by replacing the file at the
same path — no code or database change needed.
