A living backlog of ideas, feature requests, bug fixes, and polish items for the Rock Cottage app.

## 📋 Features & Enhancements

- [ ] **Shopping list batch confirmation ("Got it" button)**
  - *Context:* Currently, tapping an item immediately marks it as picked up and removes it from the open list.
  - *Change:* Allow users to select 1 or more items from the shopping list (with checkboxes/selection state), then tap a single confirmation button (e.g. **"Got it"**) to mark all selected items as picked up at once.

- [ ] **Shopping pickup activity tile in Home feed**
  - *Context:* Keep everyone in the cottage informed when someone goes into town and grabs groceries/supplies.
  - *Change:* When a user confirms picking up item(s), generate an activity tile on the Home dashboard feed showing what was picked up and by whom.

- [ ] **Simplify Public Goods (Bringing) items — remove packed/selection state**
  - *Context:* Currently, Public Goods items have a checkmark toggle to mark them as "packed".
  - *Change:* Remove the selection / packed toggle from the Public Goods screen so items simply display as claimed/assigned without an unnecessary check-off state.
